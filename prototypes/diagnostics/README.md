# SOMA Diagnostics UI 原型

仅用于 UI 确认；正式功能尚未开发。基于 v2.4.8 的颜色、字体、按钮与暗色画布风格，使用真实 PySide6 控件和 QPainter 渲染，不是 AI 绘制界面图。

## 三张效果图

- `01-overview.png`：A/B 原图、统一坐标边缘叠加、配准摘要、位移曲线与核心指标。
- `02-local-displacement.png`：圆孔局部切向放大，青/橙有效点、红色剔除点、法向差及明确标注 ×4 的独立位移示意线。
- `03-profile-gradient.png`：同一位置灰度/梯度双曲线、主峰定位、B 次峰与边缘宽度不可报告状态。

全部为 1500×1020 实际 QWidget.grab PNG；文件可重新生成。图片包含 DEMO 标识。两张缩略图为模拟源示意，不是实拍 TIFF，也没有真的执行显示的配准步骤。

## 运行

依赖：Python 3.10+、PySide6、NumPy（均已在当前机器的捆绑运行时可用）。在本目录运行：

```powershell
python prototype.py
python prototype.py --capture
```

如果系统 `python` 不可用，当前机器可运行：

```powershell
& 'C:/Users/12409/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' prototype.py
```

`--capture` 使用 Qt offscreen 平台，显式加载 Windows 中文字体，以避免截图出现方框字。其他系统需要安装中文字体。

## 已实现的演示交互

- 三个主视图即时切换；A/B 边缘、拟合参考圆、剔除点、卡尺显示开关。
- 总览滚轮缩放、右键拖动、适应窗口、1:1、进入局部视图。
- 总览图点击角度，更新曲线竖线、角度和数值；曲线点击/悬停反向定位总览选区。
- 曲线带符号/绝对/统一参考径向位置三种口径，滚轮切换全角度/局部角度范围。
- 进入 Profile 会按所选角度更新 B 主峰位置；多峰时不显示强制宽度。

局部视图展示固定切向区段，尚不支持点击局部点反算角度；曲线 hover 提供侧栏读值，没有独立浮层。局部图的 1:1 尚无物理图像重采样意义，只演示缩放；完整图上的 1:1 以模拟源像素显示。

导入、方向对齐、配准、开始分析和导出是流程占位，点击会明确提示 DEMO。不读取用户图像、不调用任何正式检测或配准算法，不可用于量测。当前使用可运行的 PySide6 交互原型，未额外提供 HTML 版本。

## 模拟数据与设计口径

角度 0–359°，向外为正，模拟 X/Y 均为 0.1 μm/px；曲线：

`delta = .07*sin(2*angle) + .11*exp(-((angle-135)/22)^2) + .015`（sin 输入弧度）。

250–270° 标记为无有效 B 对应；统计仅使用其余 339 个角度，覆盖率 339/360=94.17%。曲线在缺失区断开。总览仅每 5°绘制点，属于 UI 稀疏显示，不改变统计集合。

右侧 RMS、P-V、Mean、P95、Max 都从同一 delta 计算。所示圆心为预设示意参数，非实际拟合；直径是有效角度上的径向均值 ×2，不能代替未来正式拟合结果。B 的模拟剖面有主跃迁及 +0.8 μm 次跃迁；梯度为模拟剖面数值导数，并非卡尺算法输出。主峰位置用跃迁中心示意。

真实开发需直接使用 collector 原采样数据，图表区分原始/平滑灰度、梯度单位 DN/px 或 DN/μm、采样方向及坐标。数字显示精度仅供 UI 评审，不代表设备不确定度。
