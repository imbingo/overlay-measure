# SOMA Vision Metrology

## V2.3.0 性能与孔阵列识别

- 性能改动 1：多 ROI 通用边缘点均匀限采样、深层取消响应及轻量化非激活结果绘制，降低大量 ROI 下的卡顿和内存占用。
- 识别改动 2：孔阵列自动识别使用全局与局部阈值候选，不再在多层汇总后静默截断为 32 个候选；候选和时间预算可随 Recipe 保存。

## V2.2.7 亮环孔与椭圆圆度修复

- 支持将一张本地图像直接拖到画布导入：单图导入当前图像，双图按落点导入上/下层；计算期间禁用拖入，失败不替换原图。

- 圆形/椭圆 ROI 支持从亮环、暗孔及光晕中选择完整清晰边界，再进行亚像素拟合。
- 修复椭圆 ROI 蒙版和隐藏的方向极性影响区域分割的问题。
- 测圆度请选择“椭圆区域（计算圆度）”；保留长短轴、直径及椭圆圆度的物理单位计算和导出。
- 椭圆圆度为 `(长轴-短轴)/2`，并非最小区域圆度。多个真实同心边界仍需缩小 ROI 明确目标。

## V2.2.6 结果交互与界面修复

- 保留 V2.2.4 顶部工具栏布局和按钮样式，继续直接显示单双图、上下层导入、重置、分析 ROI、运行与导出。
- 结果表支持多选复制、工程模式右键批量删除，并固定显示可拖动的横向滚动条。
- 取消计算仅在任务运行时显示，并放置在进度条旁边。

## V2.2.5 结果栏批量操作与横向滚动修复

- 识别明细、对位结果、尺寸结果和重复性分析统一支持鼠标拖选、`Ctrl/Shift` 多选、`Ctrl+A` 与 TSV 批量复制，并可选择包含表头。
- 显式保留可见的横向滚动条，按完整单元格文字计算列宽，支持像素级拖动及 `Shift + 滚轮` 横向浏览。
- 工程模式可右键删除单条或多条结果；批量记录按完整测量次数排除并重算均值、3σ、PV和最终导出，生产模式保持只读。
- 删除识别或几何结果时使用稳定 ID，同步使依赖的对位、坐标系、标注和尺寸结果失效，原始图像和 ROI 保留。

## V2.2.4 视图保持与测量轮廓吸附

- 新建或切换 ROI 时不再重复重置同一张图像的缩放和平移状态。
- 测量工具点击已识别圆/椭圆轮廓时自动吸附到中心，并显示选取顺序编号。
- 圆心距、直径及两圆心建轴增加要素类型校验，误点空白区域时给出明确提示，不再静默创建普通点。

## V2.2.3 ROI 交互、坐标系识别与孔阵列测试数据

- ROI 改为明确的选择后编辑流程：首次单击只选中，已选中 ROI 可在内部拖动整体，并通过控制点调整圆、圆环、卡尺圆、矩形、椭圆、矩形环和近似直线。
- 空白单击或 `Esc` 取消 ROI 与卡尺选择；空白拖动新建 ROI；圆形 ROI 强制保持正方形包围框。中键或按住空格后左键拖动画布，右键只用于管理菜单。
- ROI 移动和缩放使用预览事务，鼠标释放后按稳定 ROI ID 一次性提交，只清除该 ROI 的旧识别和关联测量；一次拖动只生成一条撤销记录。
- 坐标系增加可读名称、稳定 ID、层、建立方式、附加旋转角、原点和引用要素说明。坐标标注使用专用选择窗口，切换候选时图像工作区同步高亮对应坐标轴。
- 新增 `sample_data/v2_2_3_hole_array/` 背光孔阵列测试数据：5 x 4、孔径 120 μm、孔距 200 μm，并提供上下层已知亚像素偏移、真实值 JSON、测试 Recipe 和可重复生成脚本。

## V2.2.2 画布交互与完整图像导出

- ROI 以画布为唯一操作入口：空白拖动直接新增，点击 ROI 进入编辑，空白单击或 `Esc` 取消选择，复制、删除及按层清理统一使用右键菜单。
- 删除右侧重复的新增、复制、删除、ROI 来源、应用参数和清理按钮；ROI/算法参数变化会立即使旧结果失效，下次运行直接使用新参数。
- 几何和测量工具增加选点进度、悬停高亮、预览线/三点圆、`Backspace` 撤销、`Esc` 取消、连续测量和图上尺寸标注。
- 图像来源同时显示父文件夹和文件名；Excel 按每次/每层导出完整原图工作区，保持比例并叠加全部 ROI 和绿色识别边界。

## V2.2.0 量测正确性、状态安全与后台预览

- 圆、稳健圆和最小外接圆在标定后的物理坐标中计算，正确支持 X/Y 非等比例像素；最小外接圆不再误用最大 Feret 直径。
- 单个 ROI 失败不会清除其他成功轮廓，界面和 Excel 均保留 ROI 稳定 ID、层、编号、状态和错误原因。
- 自动识别与 ROI 预览改为后台线程，支持进度和取消；批量图片按路径惰性加载，降低大量重复测量时的内存占用。
- 生产模式同时锁定画布和后端 ROI 修改入口；模式、图像、ROI、配方或算法状态变化会使旧结果明确失效。
- ROI 参数改为显式应用，并增加上下文控件、20 步撤销/重做、恢复任务状态和 CSV 导出限制提示。

## V2.1.0 手动多 ROI 与轮廓量测

- 每个 `Mark/层` 可创建、复制、删除并切换任意数量的手动 ROI；界面按 `ROI 1、ROI 2...` 显示，内部使用稳定 ID。
- 旧版单 ROI 配方会自动迁移为对应层的 `ROI 1`，保存后记录全部 ROI、来源及基准/待测轮廓稳定 ID。
- “分析 ROI 区域”会分析当前 Mark 上下层的全部 ROI；识别明细、批量快照、几何量测和 Excel 均保留每个 ROI 的独立结果。
- 对位偏差只由现有“基准轮廓 / 待测轮廓”选择决定，不新增主 ROI。所选 ROI 被修改、删除或识别失败后，选择与旧结果会失效并要求重新选择。
- 画布同时显示当前层全部 ROI 与识别轮廓；点击 ROI 或轮廓会同步 Mark、层和 ROI 编号，当前 ROI 使用高亮编辑样式。
- 椭圆直径、椭圆圆度、质量等级和算法路径继续按每个 ROI 独立保存与导出。

## V1.9.0 更新说明

### 椭圆物理圆度

- 椭圆拟合新增物理长轴、短轴、椭圆直径和椭圆圆度，支持 X/Y 非等比例像素与旋转椭圆。
- 椭圆直径定义为 `(物理长轴 + 物理短轴) / 2`；椭圆圆度定义为 `(物理长轴 - 物理短轴) / 2`。

- 识别明细新增“第1次、第2次……、全部”选择器；单次选择同步切换图像和拟合轮廓，“全部”只合并表格并保留最近一次单次预览。

- 旧配方中的 `a/b/c` 候选选择按原检测排名映射到新编号；无法映射时按现有形状和尺寸规则回退并提示。

## 运行

```powershell
python -m pip install -r requirements.txt
python .\main.py
```

Windows 下可以直接双击仓库根目录的 `start_overlay_measure.bat`。启动器会在当前项目根目录创建独立的 `.venv`，首次运行时自动安装并校验 `requirements.txt` 中的依赖，然后启动软件。后续运行会复用该环境；只有依赖文件变化或环境损坏时才会重新安装。

自动安装仍要求电脑已安装 64 位 Python 3.10-3.13。首次安装依赖需要能够访问配置的 Python 软件源。需要强制重新安装依赖时，可在 PowerShell 中执行：

```powershell
.\start_overlay_measure.bat -ForceInstall
```

正式发布包使用：

```powershell
.\scripts\build_release.bat -Python "D:\python\python.exe"
```

输出位于 `release\`。详细说明见 [`installer/README.md`](installer/README.md)。

如需生产环境完全复现当前依赖，可使用：

```powershell
python -m pip install -r requirements.lock.txt
```

## 主要功能

- 支持 Single Image / Dual Image 测量模式。
- 支持手动 ROI 与自动识别测量。
- 支持圆、椭圆、矩形、环形 ROI 等 mark 拟合流程。
- 支持批量测量与重复性分析。
- 支持配方 JSON 保存/加载、本机配方库、共享配方目录、收藏和最近使用快捷切换。
- 支持工程模式修改本机配方库位置，并安全迁移配方签章与使用状态。
- 支持生产/工程权限隔离、配方 SHA256 完整性校验和生产测量前置检查。
- 支持通过、超限、无效、异常四态结果，以及输入文件和参数快照追溯。
- 支持 Excel 结果导出。
- 支持样例图片和样例 recipe 快速验证流程。

## 生产模式

- 软件启动后默认处于生产模式。
- 初始工程模式密码为 `admin123`；进入工程模式后可在“产品信息”页修改密码，正式部署后应在受控流程中修改并限制知悉范围。
- 生产模式只接受“已验证”且 `.sha256` 签章匹配的配方。
- 运行日志、未完成任务和测量追溯档案默认保存在 `%LOCALAPPDATA%\OverlayMeasure`。

## 历史版本

仓库根目录始终放当前推荐版本。更新前版本已移动到 `legacy/v1.0.5/`，同时 Git 历史也保留了完整提交记录。
