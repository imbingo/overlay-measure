# SOMA Diagnostics / 成像诊断（V2.5.1）

V2.5.0 存在“更多”按钮未显示的入口问题，请使用 V2.5.1 或更新版本。切换工程模式后，按钮位于图像工具栏右侧、“分析 ROI”左侧。

## 使用

1. 进入工程模式，在“更多”打开“SOMA Diagnostics / 成像诊断”。原“图像诊断与边缘分析”仍是原有单图工具。
2. 分别导入 A（历史）和 B（当前）。原文件保留，显示映射不会写回原灰度。右侧折叠参数中确认 A/B **原生** X/Y μm/px；B 旋转后软件自动交换轴标定。
3. 若扫描方向已知相差 90°/180°，先用 B 方向下拉框统一方向。图像通过数组整数索引旋转，无插值，保存原始→旋转坐标变换。
4. 在 A 拖动外接正方形指定参考圆孔环带；内径比例、卡尺数/宽度、极性、目标边缘、搜索方向、Gaussian、梯度阈值、步长及 RANSAC 位于右侧。导入时有中心默认 ROI，分析前应确认它包含目标边缘。
5. 选择配准方法并点击“配准”，通过后点击“开始分析”。分析在独立线程运行，计算期间禁用会改变输入的操作。
6. 切换 Overlay / Displacement / Profile。在曲线上悬停或点击选角度；点击叠加图选择物理角度；局部放大定位当前角度。滚轮缩放、原有中键/空格拖动、适应窗口、1:1 均沿用 ImageCanvas。曲线滚轮放大角度区，“0–360°”恢复全区。
7. 导出目录下自动创建带时间的独立子目录，包含 Excel、所有 CSV、session.json、固定口径位移 PNG、当前图像和当前曲线 PNG；Profile 视图还输出当前剖面 CSV。

## 三种配准口径

**手工独立对应点 / 刚性（默认）**：用工具栏选择“A/B 交替点击对应点”，在两张原图选择至少三对非共线、独立于被测孔的稳定特征点；按编号对应。不估计尺度、剪切或非刚性形变。输出物理坐标刚性矩阵、旋转、平移、对应点和残差。默认残差门槛 0.2 μm，并要求残差低于特征分布跨度的 2%；可在右侧调整绝对门槛。手工点选定位精度会限制配准精度，不是亚像素检测不确定度认证。

**独立特征区 / 平移**：在 A 拖动独立矩形，要求与被测孔 ROI 不相交、共同视场至少 95%。先相位相关，再用仅含平移的 ECC 细化。要求相位响应 ≥0.3、ECC ≥0.6、位移小于基准区各边长的 1/4。此方法适合已统一方向、初始位置相近的两图；未知旋转或视场变化较大时用独立点刚性方法。相关响应不是几何残差；不输出虚假的物理残差值。

**圆心平移 / 仅形状**：先分别在 A/B 指定初始圆环 ROI，用同一检测器估计中心，再迭代同一参考采样框架下的中心平移。它会消除整体平移，单个理想圆孔不能确定旋转，不可据此判断真实圆心漂移，也不代表设备全部几何误差。保存数值收敛量，明确不把它叫作独立配准残差。

配准不可靠时拒绝分析。分析覆盖率不足 70% 或差异接近搜索带宽时，结果标为“不可靠 / 仅供排查”，导出亦保留这个状态，不能当作可靠定量结论。门槛是首版排查保护，不是经过计量认证的测量能力声明。

## 共用检测器与坐标

`caliper_circle_detector.detect_caliper_circle` 是正式量测与 Diagnostics 唯一共用的圆卡尺检测器。新增 keyword-only `diagnostics=None` 与 `sampling_transform=None`；原有默认调用的采样、梯度峰、一致性选择、RANSAC、拟合、dtype 和返回字段没有替换。

Diagnostics 在 A 旋转后像素坐标定义 ROI。A 正常检测；B 使用下列坐标链将每个原有卡尺采样位置直接映射到 B 原始灰度，再调用同一双线性采样与梯度峰算法：

```
A oriented px → A calibrated μm → inverse(B μm→A μm rigid)
              → B oriented px → native B pixel index / export
```

因此没有把配准后的插值显示图送入边缘检测，也无需把物理圆环近似为 B 的像素圆。各向异性标定引入的像素坐标比例来自真实标定，**不是自由仿射形变配准**。在 B 配准背景选项中出现的插值只用于显示。

卡尺的 profile step/width/梯度阈值按共同 **A ROI 像素采样框架**定义，B 的真实采样坐标和映射保存在追溯数据里。Gaussian 仍按现有算法先在各自原生灰度执行，单位是原生 px；两图像素尺寸不同时会提示物理平滑宽度不同，需确认可比性。这里不偷偷改动正式检测器 Gaussian 的含义。

同一张图 + 同一个 ROI + 同套参数，在默认采样框架下，Diagnostics 与正式卡尺返回相同的边缘点及卡尺拟合结果。诊断的物理参考圆额外调用已有 `measurement_units.robust_circle_um` 在最终有效点的物理坐标上拟合，以正确处理 X/Y 各向异性；原生卡尺的像素拟合中心/半径也单独保存，不能混淆这两种口径。直径显示的是相对物理参考圆心的平均径向直径。

ImageData 的 float32 可以精确表示所有 8-bit/16-bit 无符号整数灰度；Gaussian 和亚像素插值仍有正常浮点舍入。变换、对应、物理坐标与差异统计使用 float64。原始文件 SHA256 与导入后灰度相互独立保存。

## 曲线与对应

- X 向右、Y 向下，物理角度顺时针，0° 指向右，位移向孔外为正。
- 固定 360 个物理角度。仅在相邻有效卡尺之间局部插值径向位置，最大角间隔 30°；缺失或拟合剔除卡尺之间不补成有效对应。逐角度表明确标注局部插值口径，session.json 另存有效区间。
- 不按数组序号对应；支持不同点数。一般轮廓尚未开放 UI，首版专注环带卡尺圆。
- Mean / RMS / P-V / P95 absolute / Maximum absolute 仅使用有效角度；有效覆盖率 = 有效角度数 / 360。RMS 包含均值，P-V 为带符号最大值减最小值。
- 三条查看口径为带符号差、绝对差、A/B 相对于同一 A 物理圆心的径向位置。
- “各自圆心对齐”是额外的形状口径，明确消除中心平移；不改变导出的独立基准注册结果。
- px 位移定义为差异向量映射到参考 A 像素轴后的带符号欧氏长度，不能用 μm 除以平均像素尺寸；各向异性时以 μm 为主要报告单位。
- 位移视图仅把法向短线段放大，倍率可见；实际亚像素点不移动。

## Profile 解释

所选角度定位最近的实际卡尺，并显示真实卡尺角度。两图沿同一配准后物理轴取原灰度；滤波灰度、梯度、全部候选峰、过阈值峰和被选峰直接来自检测时的可选采集，不另写峰选择器。

梯度由原检测器 DN/参考采样 px 换成 DN/μm；峰值幅值按检测器 score 报告。曲线虚线为被算法选中的位置，点线为候选位置。剖面距离以 A 选峰为 0，正方向按当前搜索方向注明（向孔内或孔外）；圆周差异曲线始终是向外为正，二者不要混用。

Profile 不随“各自圆心对齐”人为移动灰度曲线。若 B 点被剔除，其峰位置仍可查看，但只标为候选峰位置差，不算有效局部测量。10–90% 宽度只对一个峰、近似单调、两端平台充分且完整覆盖的跃迁报告；否则显示原因，绝不强填宽度。

## 导出与复现

- `analysis.xlsx` / `csv/`：两种口径指标与逐角度表，A/B 原生边缘点、有效状态、配准表；没有三位小数舍入。
- `session.json`：版本、路径、导入/当前文件 SHA256、文件变更标记、原 dtype/尺寸、原生及旋转后标定、整数旋转矩阵、刚性矩阵及基准/可靠性、ROI 坐标框架、DetectionParams、全部卡尺剖面与候选峰、最终状态、有效角区间。
- `edge_displacement.png` / `center_aligned_displacement.png`：两种口径的固定曲线，含单位、零线和缺失断线；UI 另输出当前视图及当前选中剖面 CSV。
- 正式 `export_results` 的字段与默认三位小数行为不变；新增 `export_data_tables` 复用原 pandas/openpyxl/CSV 写入与样式基础设施。

当前版本不含 FFT/PSD、SPC、数据库、非刚性配准、设备健康评分或自动设备归因。合成测试和 UI QA 不能替代使用实际 LSM 图像进行验证。
