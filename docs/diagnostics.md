# 成像诊断（V2.6.0）

## 只需三步

1. 在主页面双图模式导入要比较的上下层图像，沿用原有 ROI / 配方完成识别。
2. 在工程模式工具栏点击 **成像诊断**（小窗口显示“诊断”，也可从“更多”进入）。自动带入当前 Mark、当前批次的图像和已识别轮廓。
3. 点击蓝色 **自动配准**，切换 **边缘叠加 / 局部位移 / 灰度梯度** 查看结果。

不需要重新导图、画 ROI、选择配准方法或点对应点。单对轮廓直接使用，多轮廓时才出现比较对象选项，并优先沿用主页面当前选择。

## 大图与三个视图

- **边缘叠加**：青色上层、橙色下层，显示主页面原始识别点。配准后自动将轮廓放大到合适尺寸；滚轮缩放，中键/空格拖动。
- **局部位移**：定位当前角度，显示放大的位移短线段。倍率可见，原始点位不移动。
- **灰度 / 梯度**：沿同一配准物理线查看两图原始灰度、Gaussian 后灰度及梯度。虚线为主页面轮廓的角度插值位置，点线为剖面候选峰；不运行第二套边缘识别。

点击图像选角度，曲线联动；曲线上悬停/点击也会定位图像。拖动图像和曲线间分隔条可调整面积。“适应窗口”显示完整轮廓，“局部放大”定位选中边缘。

主页面重新导图、识别或切换批次后，点击 **同步主页面** 再点 **自动配准**。重新打开诊断页也会同步。

## 自动配准的含义

直接使用主页面已识别的两个圆心，执行物理坐标平移对齐，无需手工点选。已知扫描方向不同，可选择下层旋转 90°/180°/270°后再次自动配准；直角旋转不插值。

**圆心对齐会消除整体平移，因此这里比较相对轮廓形状。** 单个理想圆孔不能可靠确定未知旋转，也不能用对齐图判断真实圆心漂移。主页面原始圆心及其差异保留在检测结果和导出记录中。

请将上下层用于实际希望比较的两次成像；不同物理结构之间的差异不应直接归因为设备变化。

## 数据复用与隔离

- 复用主页面 DetectionResult 的边缘点、圆心、直径和剔除点；不重跑卡尺或重新拟合圆，不改变正式量测口径。
- 原图、参数、ROI 和结果复制为独立只读快照；旋转、平移只改变诊断坐标，不修改配方、正式点集或 DX/DY。
- 共用主页面像素标定与 measurement_units 换算。按物理角度比较，不按数组索引对应；不同点数局部插值，大缺口不连接，两组点分别按自己的采样间距限制插值。
- 覆盖不足或主页面未通过质量门槛时，仍可查看排查，但标为“仅供查看”，不作为有效量测结论。
- 主页面批量历史可能只保存最多 256 个轮廓点。检测到抽样结果时会提示仅供预览；完整诊断应在主页面对当前组重新识别，不能把抽样轮廓冒称为完整测量点。
- 数值小数位数不代表设备测量不确定度。

## 导出

包含完整精度 Excel/CSV、主页面原生边缘点及剔除状态、逐角度位移、位移曲线 PNG、当前视图 PNG 和 session.json。在灰度/梯度视图导出时，还保存当前剖面 CSV/JSON。

追溯记录包含主页面参数/ROI、检测结果快照、配准方式、方向、标定、路径、导出时文件 SHA256 和灰度数组 SHA256。原 ImageData 没有导入时文件 hash，因此不会把“导出时文件 hash”冒称为原始导入文件认证 hash。

剖面沿同一物理采样线独立取值，候选峰用于解释灰度变化。标记来自主页面点集的角度插值，不冒称为这条新采样线重新选中的峰。
